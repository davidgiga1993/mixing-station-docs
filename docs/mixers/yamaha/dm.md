# Yamaha DM Series

## DM3

Mixing Station supports all models of the DM3 mixer series, but there are some limitations:

- Scenes can only be recalled. Saving/deleting is **not** possible
- Access to the USB player is not possible due to firmware limitations

| Access Mode       | Maximum number of connections |
|-------------------|-------------------------------|
| FoH               | 3                             |
| Personal / custom | 10                            |

## DM5 / DM7

| Access Mode       | Maximum number of connections |
|-------------------|-------------------------------|
| FoH               | 3                             |
| Personal / custom | 48                            |

## Metering

In personal monitoring mode metering it received from the mixer using multicast (`239.192.0.164`).
Make sure your network equipment (wifi AP, Router, ...) allows multicast traffic!
